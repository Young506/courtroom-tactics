# 战术室 COURTROOM

面向 PC、Android 和 iPhone 浏览器的开源篮球战术画板。支持 2D 编辑、3D 战术预览和 MP4 视频导出，无需注册登录。纯静态网页，无需服务器端代码或 API 密钥。

## 3D 预览

- 点击画板上方的「3D 预览」，在立体球场里观看现有战术。
- PC 左键拖动旋转、右键拖动平移、滚轮缩放；手机单指旋转、双指平移、捏合缩放。支持斜视、俯视、底线、侧面四种预设视角。
- 3D 模式使用现有时间轴同步播放跑位、传球、运球、掩护和投篮动作。
- 支持路线显示开关、重置视角，以及将当前 3D 画面保存为 PNG。
- 「开始讲解」模式支持切换 2D / 3D；讲解文字和常用按钮字号已增大，适合 PC 阅读。
- 3D 画布获得焦点后，可用方向键旋转、Shift + 方向键平移、+ / − 缩放、0 重置摄像机。
- 需要支持 WebGL 2、开启硬件加速的新版浏览器。Three.js 随网站托管，不依赖在线 CDN。

在线使用：[战术室](https://young506.github.io/courtroom-tactics/)

## 使用

2D 画板可直接打开 `index.html`。3D 预览需要通过 HTTP 服务或线上网站打开；在项目目录启动静态服务：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

浏览器访问 `http://127.0.0.1:4173`。建议使用最新版 Edge、Chrome 或 Firefox。

## 手机操作

竖屏底栏可切换画板、步骤讲解、战术库与新建战术；绘制工具横向排列在球场下方。可以拖动球员，也可先选中球员再点目标位置；动作工具支持先点球员再点终点。步骤、属性编辑、JSON 备份和图片、视频导出均保留。

## MP4 视频

「导出战术 → 导出战术视频」可选择 2D / 3D、全部步骤 / 当前步骤、横屏 16:9 / 竖屏 9:16、720p / 1080p。手机默认竖屏 720p。视频包含战术名称、步骤名称、序号与完整说明；长说明分页展示并延长停留时间。3D 使用打开导出窗口前设置的固定镜头。

声音可选无声、逐步骤录音（或上传 MP3 / M4A / WAV / WebM）和离线中文自动朗读。自动朗读使用约 4 MB 的音节库，声音较机械，可先试听。录音权限需要 HTTPS 或本机 localhost；拒绝权限后仍可上传音频。视频会等待整段讲解结束。

优先使用浏览器原生 WebCodecs 生成 H.264 / AAC MP4；缺少编码能力时尝试 MP4 MediaRecorder 兼容模式。目标为 30 帧/秒；兼容模式实时录制，帧时间随设备负载变化。不会将 WebM 改后缀冒充 MP4。不支持 MP4 编码的设备会收到明确提示，可换新版浏览器或在电脑导出。

导出时保持页面在前台，切到后台会取消本次导出。可以随时取消重试。单次视频最长 10 分钟，较长战术可按步骤分段导出；手机内存不足时优先 720p。生成后可先播放，再下载或用系统分享保存。浏览器实际支持情况仍需在目标手机上验收。

## 操作

- 选择工具拖动球员。选中球员后可改号码、设置持球人、删除该球员。
- 跑位、运球、传球、掩护、投篮：从球员拖向目标位置。持球动作须从当前持球人开始。传球需拖到另一位进攻球员。
- 投篮自动对齐上半场篮筐；全场时拖向下半场会对齐另一篮筐。
- 每个步骤保存自己的初始站位和动作。添加步骤会使用当前步骤动作完成后的站位；已有后续步骤是独立快照，修改前一步后可按需调整后续步骤。
- 半场切全场保留上半场站位；全场切半场时，下半场坐标旋转映射到上半场。撤销可恢复。
- 支持 1v1、3v3、5v5 初始阵容，防守球员显示切换，自由画笔，撤销/重做。
- 时间轴支持添加、复制、删除步骤，速度选择，循环播放，暂停与继续。
- 开始讲解进入大画板模式，显示当前步骤讲解，Esc 退出。
- 导出 PNG / SVG 当前画板；JSON 备份全部步骤并可导入；打印全部步骤讲义，可在浏览器打印面板中存为 PDF。

快捷键：V 选择、R 跑位、D 运球、P 传球、S 掩护、H 投篮、B 画笔、E 擦除、空格播放/暂停、左右方向键切换步骤、Delete 删除所选对象、Ctrl+Z 撤销、Ctrl+Shift+Z 重做。

## 数据保存

战术自动保存在当前浏览器的 localStorage，录音保存在 IndexedDB，视频在本机生成；战术与声音不上传服务器。换浏览器、换电脑或清理站点数据前，请导出 JSON 文件备份战术，并另行保留原录音；JSON 不包含录音。网站不同域名（含本地预览与线上站点）的保存空间相互独立。本版不提供跨设备云同步或多人协作。

## 验证

```sh
node --check app.js
node --check engine.js
node --check court3d.js
node --test engine.test.cjs review-features.test.cjs
```

`engine.js`：可独立验证的数据、站位接续、球权、动画采样与导入校验。
`app.js`：画板渲染、交互、保存、导入导出与讲解模式。
`styles.css`：桌面布局、窄屏适配与打印样式。

`experience.css`：大字号、3D 控件与新版响应式布局。
`court3d.js`：立体球场、球员模型、摄像机与 3D 截图。

18 项逻辑测试覆盖原有动画与数据逻辑，以及摄像机手势、视频尺寸、说明分页、配音时长、MP4 签名和离线语音索引。测试要求 Node.js 18 或更新版本。浏览器生成的实际样片另行验证 H.264 / AAC、分辨率和完整解码；自动化手势测试不能代替 Android / iPhone 真机验收。

## 部署到 GitHub Pages

将项目放入公开 GitHub 仓库，在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 **main**，文件夹选择 **/ (root)**，保存并等待部署。网站直接从仓库根目录启动。

部署到其他静态托管平台时，将网站根目录设为 `.` 即可。无需服务器端代码、密钥或环境变量。
